# Krypton Documentation

The documentation sources for the Krypton monorepo. They are built with
[mdBook](https://rust-lang.github.io/mdBook/).

```console
$ mdbook serve docs     # local preview at http://localhost:3000
$ mdbook build docs     # output in docs/book/
```

The book covers the library, the CLI, the container format, the threat model,
and the roadmap. Start at [Introduction](src/intro.md).
